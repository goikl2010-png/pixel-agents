The launcher requires exact `codex-cli 0.152.1`, the reviewed global-before-`exec` capability surface, and a successful read-only `codex login status` in the same managed environment. The first run is fixed to one dispatch, a 120000 ms timeout, a 30000 ms lease, a 10000 ms heartbeat, a three-failure circuit, a stop file, and `workflow_mutation_adapter: false`. No automatic follow-up is possible. A stale checkout, mismatched hash or target, GitHub drift, absent authentication, failed governance gate, stop signal, timeout, lease/recovery ambiguity, or attempted second dispatch fails closed.

Before invocation Alex must prepare a rollback by ensuring the stop-file path is available and saving the exact HOLD restoration change. On termination or failure, Alex restores `activation_hold: true`, removes the ephemeral process environment, preserves Runner evidence, and does not redispatch after ambiguity. The Runner does not mutate governance or restore HOLD itself because workflow mutation is forbidden.
